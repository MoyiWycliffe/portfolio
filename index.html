01 — About

More than writing code. I build systems.

My work sits at the intersection of software engineering, web development, cybersecurity and product building. I enjoy taking an idea, breaking the problem down, designing the system, writing the code, securing it and eventually putting it in production.

I don't want to only know how to use a technology. I want to understand what happens underneath it — how requests move through a system, how databases store information, how authentication works, where applications fail and how software behaves in the real world.

  • Software engineering and full-stack web development
  • Backend APIs, databases and system architecture
  • Cybersecurity and secure application design
  • Building SaaS products and practical digital systems
